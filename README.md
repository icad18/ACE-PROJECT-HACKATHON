# Marketplace Application

This is a monorepo for a Shopee-like marketplace application, built with a NestJS backend and a Next.js frontend.

## Project Structure

-   `backend/`: Contains the NestJS API.
-   `frontend-web/`: Contains the Next.js web application.
-   `frontend-mobile/`: (Planned) React Native mobile application.

## Technologies Used

**Backend:**
*   NestJS (Node.js)
*   PostgreSQL (Database)
*   TypeORM (ORM)
*   JWT for Authentication

**Frontend (Web):**
*   Next.js (React Framework)
*   Tailwind CSS (Styling)
*   Axios (HTTP Client)

**Frontend (Mobile - Planned):**
*   React Native / Expo
